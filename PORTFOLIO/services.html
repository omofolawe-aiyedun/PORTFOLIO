Services

Ways to work together.

Each offer is a custom website for a local business. Prices are discussed per project, so nothing here is a made-up package price.

New business website

For a business that does not have a site yet. You get the pages customers expect, written and arranged so the next step is obvious.

Usually that means a home page, an about page, a services page, and a contact page, laid out for both a computer and a phone.

Redesign of an existing site

For a site that already exists but is hard to read, hard to use on a phone, or no longer looks like the business.

The useful parts stay. The structure, type, and layout are rebuilt so a customer can find what they came for.

Updates and care

For a site that is already live and needs small changes: new words, a new photo, a new section, or a fix.

This keeps the site current without starting over.

Simple backend features

When a project needs forms or stored information, I can work with PHP and MySQL to add practical functionality.

The scope stays focused on what the business and its customers actually need.
